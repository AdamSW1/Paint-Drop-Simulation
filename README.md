# Paint Drop Simulation

## Overview

The app is a simulation of paint drops with a pattern generator  

### basic controls
- left clicking in the app will add a new drop  
- middle click will clear all colours on the screen  
- pressing `m` will start a pattern generation algorithm  
- and pressing `e` will end the pattern generation  

### colour picking controls
By default the drop colours will be random.
This can be changed with several different inputs.
- pressing `r` will change the paint drops to <span style="color:red">red</span>.
- pressing `g` will change the paint drops to <span style="color:green">green</span>.
- pressing `b` will change the paint drops to <span style="color:blue">blue</span>
- pressing `y` will change the paint drops to <span style="color:yellow">yellow</span>.
- pressing `v` will change the paint drops to <span style="color:violet">violet</span>.
